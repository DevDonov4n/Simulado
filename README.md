# Simulado preparatório — Assistente de Veterinária

Webapp independente para praticar conhecimentos do ensino médio como preparação
para uma avaliação de ingresso no curso de Assistente de Veterinária.

## Como usar

Abra `index.html` em um navegador. Não é necessário instalar dependências nem
iniciar um servidor.

O simulado inclui 20 questões de língua portuguesa, matemática, biologia,
química e ciências, e raciocínio lógico. Ao responder todas, a pessoa recebe
uma pontuação, desempenho por área, dicas relacionadas aos erros e explicações
para revisar cada questão.

> Material preparatório independente; não é uma avaliação oficial da Populos.
